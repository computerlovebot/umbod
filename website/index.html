Good to know

A few questions,
answered.

What is Umbod?

A native app that connects your AI agents to MCP tools through a local gateway. Manage connections and choose which tools your agents can use.

Which computers does it support?

We’re starting with macOS 14 or later on Apple Silicon. Windows, Linux and Intel Mac downloads are coming soon. See the download page for availability.

Does everything stay on my computer?

Your gateway and configuration run locally, and credentials are stored in macOS Keychain. Your agents and remote MCP servers can still send data to their own services.

Which MCP connections can I use?

Local stdio servers and remote Streamable HTTP servers. Desktop currently supports tools; legacy standalone SSE, resources, prompts and sampling are not supported.

What if I’m setting this up for a team?

Explore Umbod Enterprise for shared connectors, group permissions and Kubernetes deployment on your infrastructure.

Can I build it myself?

Yes. Umbod is open source. Follow the desktop build instructions to get started.
